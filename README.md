## ✨ Overview

**Tedify.stop** is a fully static e-commerce storefront built for speed,
simplicity, and easy customization. No servers, no databases — just clean
HTML, CSS, and vanilla JavaScript that deploys anywhere.

Use it as:

- 🏪 The live storefront for **Tedify.stop**
- 🧩 A **starter template** for your own online shop
- 📚 A **learning reference** for building carts and product catalogs
  without a framework

---

## 🚀 Features

- **Product catalog** — grid layout with categories, filters, and search
- **Shopping cart** — add/remove items, quantity controls, live totals
- **Checkout flow** — order summary and contact form (static-friendly)
- **Responsive design** — mobile-first, works on every screen
- **Dark / light theme** toggle
- **Zero dependencies** — no build step, no framework required
- **GitHub Pages ready** — one-click deploy
- **Accessible** — semantic HTML, keyboard navigation, ARIA labels
- **SEO-friendly** — meta tags, Open Graph, structured data
